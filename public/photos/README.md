# โฟลเดอร์รูป

วางรูปตามโครงนี้ แล้วรัน `npm run photos`

```
public/photos/<ปี>-<เดือน>/<รหัสบล็อก>/*.jpg
public/photos/2569-07/g-garden-r1/IMG_0001.jpg
```

`<ปี>-<เดือน>` ต้องตรงกับ `config/round.json` · `<รหัสบล็อก>` คือ `id` ใน `config/sections.json`

รูปเรียงตาม**ชื่อไฟล์** เพราะวันที่พิมพ์อยู่บนตัวรูป ไม่ใช่ใน EXIF
ตั้งชื่อให้เรียงถูกไว้ เช่น `001.jpg` `002.jpg`

## ลงรูปจากเบราว์เซอร์ (ไม่ต้องมีโค้ดในเครื่อง)

เปิดหน้า **`/arrange`** แล้ว**ลากทั้งโฟลเดอร์**มาวางได้เลย ไม่ต้องลากทีละหัวข้อ

```
รูปเดือนกรกฎาคม/           ← ลากโฟลเดอร์นี้อันเดียว
├── g-garden-r1/  001.jpg 002.jpg
├── p-canteen/    001.jpg
└── p-dorm/       001.jpg
```

ชื่อโฟลเดอร์ย่อยตั้งเป็น **รหัสบล็อก** (หรือชื่อหัวข้อเต็มก็ได้) ระบบจะแจกเข้าหัวข้อให้เอง ·
อันที่เดาไม่ออกจะขึ้นให้เลือกทีเดียวพร้อมกัน · กดส่งครั้งเดียวได้ทุกหัวข้อในคอมมิตเดียว
รูปถูกย่อในเบราว์เซอร์ก่อนส่งอยู่แล้ว ไม่ต้องย่อมาก่อน

**อย่าปิดหน้าก่อนกดส่ง** รูปที่ลากมายังไม่ส่งอยู่ในหน่วยความจำอย่างเดียว (สลับหัวข้อได้ ไม่หาย)

## จัดลำดับเอง / ซ่อนรูป / ใส่คำบรรยาย

เปิดหน้า **`/arrange`** บนเว็บ → เลือกบล็อก → ลากสลับ ซ่อน พิมพ์คำบรรยาย →
กด "บันทึกไฟล์" แล้วเอา `arrange.json` มาวางในโฟลเดอร์ของบล็อกนั้น → สั่ง `npm run photos`

ไฟล์หน้าตาแบบนี้ แก้มือก็ได้ถ้าถนัดกว่า

```json
{
  "order":    ["003.jpg", "001.jpg"],
  "hidden":   ["002.jpg"],
  "captions": { "003.jpg": "ก่อนทำ - หน้าอาคาร 1" }
}
```

**รูปที่ไม่ได้อยู่ใน `order` จะต่อท้ายให้ตามชื่อไฟล์** เพิ่มรูปใหม่เดือนหน้าจึงไม่ต้องจัดใหม่ทั้งชุด
ไม่มี `arrange.json` = เรียงตามชื่อไฟล์ล้วน ซึ่งเป็นสิ่งที่ต้องการอยู่แล้วเกือบทุกครั้ง

รูปไม่ถูก commit ขึ้น git (ดู `.gitignore`) เพราะไฟล์ใหญ่และเป็นข้อมูลรายเดือน
ย่อรูปก่อนวางเสมอ แต่อย่าต่ำกว่า 1600px ต้องยังอ่านวันที่บนรูปออก
