# ระบบรายงานประจำเดือน — โรงงานผลิตอาหารสัตว์ธารเกษม (CPF)

หมวด 2.x งานบริการสำนักงาน · แทนการก๊อปวางเข้า PowerPoint ทุกเดือน

> บริบท การตัดสินใจ และลำดับงานทั้งหมดอยู่ใน [`docs/PROJECT.md`](docs/PROJECT.md)

## สั่งงาน

```bash
npm install
npm run dev        # เปิด http://localhost:3000
npm run build      # สร้างไฟล์นิ่งลงโฟลเดอร์ out/
npm run typecheck
```

`npm run build` ได้ผลลัพธ์เป็น **ไฟล์ HTML นิ่ง** ในโฟลเดอร์ `out/`
เอาไปวางที่โฮสต์ไหนก็เปิดได้ ไม่ต้องมี Node บนเครื่องผู้ใช้ —
เครื่องบริษัทจึงใช้แค่เบราว์เซอร์ ไม่ต้องติดตั้งอะไรเลย

## หน้าจอ

| เส้นทาง | ใช้ทำอะไร |
|---|---|
| `/` | สารบัญ + ความคืบหน้าว่าบล็อกไหนทำแล้ว บล็อกไหนรออยู่ขั้นไหน |
| `/deck` | ทั้งเล่มเรียงต่อกัน · **ทางออก PDF** กด Ctrl+P → แนวนอน → เปิด "กราฟิกพื้นหลัง" |
| `/present` | โหมดนำเสนอทีละหน้า · ลูกศร / Space เลื่อน · `f` เต็มจอ |
| `/edit` | กรอกตัวเลขของเดือนนี้ — ทุกตารางรวมอยู่หน้าเดียว |
| `/arrange` | ลงรูป — ลากไฟล์ใส่ สลับลำดับ ซ่อน ใส่คำบรรยาย |

หน้ากระดาษที่พิมพ์ออกมาเป็น 960 × 540 pt (13.333 × 7.5 นิ้ว) เท่ากับสไลด์ PowerPoint จอกว้างพอดี

## รอบเดือนหนึ่ง ทำอะไรบ้าง

1. เปิด **`/edit`** กรอกตัวเลขของเดือนนี้ — ตาราง 12 เดือนทั้ง 9 ตารางรวมอยู่หน้าเดียว
   แต่ละแถวกรอกช่องเดียว มีค่าเดือนก่อนขึ้นให้เทียบว่าพิมพ์ผิดหลักหรือเปล่า
2. เปิด **`/arrange`** ลากรูปของแต่ละบล็อกใส่
3. ทั้งสองหน้ากดส่งแล้ว commit เข้ารีโปเอง → เว็บอัปเดตใน ~1 นาที
4. เปิด **`/deck`** ตรวจ แล้วกด Ctrl+P ถ้าต้องการ PDF

ไม่ต้องเปิด Excel ไม่ต้องก๊อปวางเข้า PowerPoint ไม่ต้องมีโค้ดในเครื่อง

## เปลี่ยนเดือนที่ทำรายงาน

แก้ `config/round.json` ที่เดียว ทั้งเล่มขยับตาม
หน้า `/edit` จะเปลี่ยนไปกรอกช่องของเดือนใหม่เองโดยอัตโนมัติ

## เพิ่ม / สลับ / ลบหัวข้อ

แก้ `config/sections.json` อย่างเดียว **ห้ามเขียนเลขหัวข้อลงในโค้ด**
เลข `2.1`–`2.13` สร้างจากลำดับใน array ที่ `lib/deck.ts` จุดเดียวในระบบ
สลับลำดับในไฟล์แล้วเลขขยับตามเองทั้งเล่ม รวมถึงในสารบัญและท้ายสไลด์

## โครงไฟล์

```
config/sections.json   13 หัวข้อ + ข้อมูลจริงถึง ก.ค. 2569  ← หัวใจของระบบ
config/round.json      เดือน/ปีของรอบที่กำลังทำ
shared/schema.ts       type ของบล็อก + ตารางหน่วย + ตัวช่วยคำนวณ (ห้ามมี logic แสดงผล)
lib/deck.ts            แปลง config เป็นลำดับสไลด์ + จุดเดียวที่สร้างเลขหัวข้อ
components/slide/      ตัวเรนเดอร์สไลด์แต่ละชนิด
app/                   หน้าเว็บ 3 หน้าข้างบน
```

## สถานะ

ตัวเรนเดอร์ครบทุกชนิดบล็อกแล้ว ยกเว้น `text` · ที่เหลือคือ**ข้อมูล** ไม่ใช่โค้ด

| ชนิดบล็อก | สถานะ |
|---|---|
| `cover` `closing` | สร้างเองอัตโนมัติ 100% |
| `monthly-matrix` | ตารางจริง (คัดลอกได้) · ซ่อนเดือนที่ยังไม่ถึงและแถวที่ว่างทั้งปี · ตารางยาวหั่นเป็นหลายหน้าเอง |
| `chart` | กราฟแท่งกลุ่ม SVG สร้างจากตารางต้นทาง ไม่กรอกตัวเลขซ้ำ |
| `list-table` | โครงตารางมาจาก `columns` ใน config ล้วน เพิ่มตารางใหม่ไม่ต้องแตะโค้ด |
| `photo-grid` | กริด 5 × 7 สามกรอบต่อหน้า · เลขกำกับ `1 (n)` และการขึ้นหน้าใหม่ระบบทำเอง |
| `photo-set` | 1–7 รูป จัดวางตามจำนวนจริง · คำบรรยายจาก `captions.json` · จับคู่ก่อนทำ-หลังทำได้ |
| `scan` | ภาพเดียวเต็มหน้า |
| `text` | ยังไม่ได้ทำ — ขึ้นเป็นช่องว่าง |

คลิกรูปไหนก็ได้เพื่อขยายเต็มจอ (กด Esc ปิด)

## รูป

**ระบบไม่ได้ผูกกับ Google Drive** รูปอ่านจากโฟลเดอร์ธรรมดา

```bash
# 1. วางไฟล์
public/photos/2569-07/g-garden-r1/001.jpg
# 2. สร้างรายการรูป
npm run photos
```

Drive เป็นแค่ทางเลือกหนึ่งในการพารูปมาลงโฟลเดอร์ — ก๊อปเอง ซิงก์ด้วย Drive for Desktop
หรือเขียนสคริปต์ดูดมาทีหลังก็ได้ ปลายทางเหมือนกันหมด รายละเอียดใน `public/photos/README.md`

### วิธีที่ง่ายที่สุด: ลากใส่หน้า `/arrange`

ไม่ต้องมีโค้ดในเครื่อง ไม่ต้องลงอะไร ใช้แค่เบราว์เซอร์

```
เลือกบล็อก → ลากรูปใส่ → ย่อให้อัตโนมัติ → จัดลำดับ → กดส่ง
→ commit เข้ารีโปเอง → Actions build → เว็บอัปเดตใน ~1 นาที
```

**ย่อรูปในเบราว์เซอร์ก่อนส่งเสมอ** เหลือด้านยาว 1200px (ยังอ่านวันที่บนรูปออก)
รูปมือถือใบละ 3–5 MB เหลือราว 150 KB · ภาพสแกน PNG ที่พอดีอยู่แล้วไม่ถูกแตะ
ระบบลองเข้ารหัสทั้ง JPEG และ PNG แล้วเลือกอันที่เล็กกว่าให้เอง

รูปทั้งชุดกับ `arrange.json` ไปเป็น **commit เดียว** ไม่ใช่ commit ละรูป

**ต้องมี GitHub Personal Access Token** กรอกครั้งเดียวแล้วเบราว์เซอร์จำไว้ให้
สร้างแบบ fine-grained เลือกเฉพาะรีโปนี้ · Permissions → Contents = Read and write · ตั้งวันหมดอายุ
โทเคนเก็บอยู่ในเบราว์เซอร์เครื่องนั้นเท่านั้น ไม่ได้ส่งไปที่ไหนนอกจาก `api.github.com`
แต่ใครเปิดเครื่องนั้นได้ก็อ่านได้ จึงไม่ควรใช้โทเคนที่มีสิทธิ์กว้างกว่านี้

### จัดรูปอย่างเดียว ไม่ส่งเข้าระบบ

หน้าเดียวกันมีปุ่ม **บันทึก arrange.json** เอาไฟล์ไปวางในโฟลเดอร์ของบล็อกนั้นเอง
แล้วสั่ง `npm run photos` — ใช้ตอนที่มีโค้ดอยู่ในเครื่องและไม่อยากยุ่งกับโทเคน

งานที่ทำค้างเก็บไว้ในเบราว์เซอร์เอง ปิดหน้าไปแล้วกลับมาต่อได้
รูปที่ซ่อนไม่ได้ถูกลบ กดเอากลับมาได้ทุกเมื่อ และ**เลขกำกับบนหน้าจัดรูปตรงกับเลขบนสไลด์จริง**

ตัวเลขทุกตัวที่ขึ้นจอผ่าน `lib/matrix.ts` ที่เดียว ห้ามคำนวณในคอมโพเนนต์
บรรทัด "สรุป" ใต้ตารางคำนวณใหม่ทุกครั้งที่เรนเดอร์ จึงเก่าตามตารางไม่ได้

เพิ่มชนิดใหม่: เขียนคอมโพเนนต์ใน `components/slide/` → เพิ่ม `case` ใน `SlideRenderer.tsx`
→ ใส่ชื่อชนิดลงใน `IMPLEMENTED` ที่ `lib/deck.ts`
