# ถอดตารางจากภาพเข้า config

**ตารางในเด็คเดิมหลายอันเป็นรูปภาพ ไม่ใช่ตาราง PowerPoint จริง** ดึงด้วยสคริปต์ไม่ได้
ทางเดียวคืออ่านจากภาพแล้วพิมพ์เข้า config — งานนี้จะกลับมาอีกทุกครั้งที่ได้ภาพใหม่

## 0. ถามก่อนลงมือ

**ผู้ใช้กำหนดคอลัมน์เองได้แล้วที่หน้า `/structure`** ไม่ต้องรอเรา
ถามก่อนเสมอว่า *จะทำเองหรือให้เราถอดจากภาพ* — อย่าตัดสินใจแทน

บล็อกที่ยังไม่มี `columns` (ตรวจซ้ำทุกครั้ง อย่าเชื่อรายการนี้):

```bash
node -e "const c=require('./config/sections.json');for(const s of c.sections)for(const b of s.blocks)if(b.type==='list-table')console.log(b.id,(b.columns||[]).length,'คอลัมน์',(b.rows||[]).length,'แถว',b.title)"
```

## 1. อ่านภาพ

ใช้ `Read` กับไฟล์ภาพตรง ๆ · ถ้าภาพเล็กจนอ่านตัวเลขไม่ออก **ขอภาพใหญ่กว่า อย่าเดา**
ตัวเลขที่เดาผิดจะขึ้นเว็บสาธารณะเป็นตัวเลขจริง

## 2. ออกแบบคอลัมน์ ก่อนพิมพ์ค่า

`ListColumn` อยู่ที่ `shared/schema.ts` · ตัดสินใจสี่อย่างต่อคอลัมน์:

| ตัดสินใจ | กฎ |
|---|---|
| `kind` | `"months"` เมื่อคอลัมน์นั้นบอก**ช่วงเดือน** · ค่าในแถวเป็น `[เดือนเริ่ม, เดือนจบ]` (1–12) |
| `merge` | `true` เมื่อค่าซ้ำติดกันในแนวตั้ง เช่น "ที่" "ผู้รับผิดชอบ" — ต้นฉบับก็รวมช่องแบบนี้ |
| `width` | เปอร์เซ็นต์ · **รวมกันต้องได้ 100** |
| `unit` | ใส่เมื่อเป็นตัวเลขมีหน่วย ดูตารางหน่วย 10 ตัวใน `UNITS` |

**ห้ามกาง 12 เดือน × 5 สัปดาห์ = 60 ช่อง** ต้นฉบับทำแบบนั้นเพื่อบอกแค่ "ทำทั้งปี"
กินครึ่งสไลด์เพื่อความหมายที่ 12 ช่องก็บอกได้ · `kind: "months"` มีไว้แทนตรงนี้

`rowsPerSlide` ค่าเริ่มต้น 9 · ตารางแถวสั้นบรรทัดเดียวใส่ได้มากกว่า (`t-clean-plan` ใช้ 22)
ตั้งสูงเกินไปตัวหนังสือไม่ได้เล็กลง — **เนื้อหาถูกตัดหายเงียบ ๆ** ต้องวัดด้วยขั้นที่ 4

## 3. เขียนลง config

แก้ `config/sections.json` ตรง ๆ ได้ (เราไม่ได้เขียนผ่านเบราว์เซอร์)
แต่ **รูปแบบต้องเหมือนเดิม** — object ที่ไม่มี object ซ้อนอยู่บรรทัดเดียว
ไม่งั้น diff บวมทั้งไฟล์ · ดู `lib/jsonFormat.ts` ว่าตัวจัดรูปแบบคาดหวังอะไร

ตรวจว่าไฟล์ยัง parse ได้และรูปแบบไม่เพี้ยน:

```bash
node -e "JSON.parse(require('fs').readFileSync('config/sections.json','utf8'));console.log('parse ผ่าน')"
git diff --stat config/sections.json    # ต้องเป็นหลักสิบบรรทัด ไม่ใช่ทั้งไฟล์
```

**ห้ามใส่เลขหัวข้อลงไฟล์** เลขสร้างจากลำดับ array ที่ `lib/deck.ts` ที่เดียว

## 4. พิสูจน์ว่าไม่ล้น — บังคับ

ตารางล้นกรอบไม่มี error ให้เห็น มันตัดเนื้อหาทิ้งเงียบ ๆ

```bash
rm -rf .next out && npx next build
(npx --yes serve@14 out -l 4173 &) ; sleep 4
node scripts/check-overflow.mjs http://localhost:4173
```

ต้องได้ `ทุกสไลด์อยู่ในกรอบ` · แล้ว **แคปสไลด์นั้นมาดูด้วยตา** ตัวตรวจไม่จับทุกอย่าง
(ตอนทำ `t-clean-plan` แถบเดือนออกมาว่างเปล่าเพราะ `h-full` ไม่มีความสูงให้อ้างในช่องตาราง
และ `merge` ที่คอลัมน์เดือนยุบ 22 แถวเหลือแถบเดียว — ทั้งสองอันตัวตรวจไม่ฟ้อง)

วิธีแคปอยู่ใน skill `verify` ข้อ 2

## 5. บอกผู้ใช้ว่าต้องตรวจ

**เราอ่านจากภาพ อ่านผิดได้** ปิดท้ายด้วยการบอกว่าถอดมากี่แถว จากภาพไหน และขอให้ตรวจ
`t-clean-plan` 22 แถวยังอยู่ในสถานะ "ถอดแล้วแต่ผู้ใช้ยังไม่ได้ตรวจ" — บันทึกไว้ใน CLAUDE.md แบบนั้นทุกครั้ง

## ห้ามเด็ดขาด

**ห้ามใส่ข้อมูลส่วนบุคคลรายคน** — วันลา เบี้ยเลี้ยง เงินเดือน ที่ผูกกับชื่อ-สกุลจริง
รีโปเป็น public และ git เก็บ history ลบทีหลังก็ยังตามอ่านได้
เคยตัด 3 ตารางจากเด็ค 1.x ทิ้งด้วยเหตุนี้ · ชื่อคนในบริบทงาน (ผู้รับผิดชอบ ผู้ตรวจ) โอเค

ถ้าภาพที่ได้มามีตารางแบบนั้น **บอกผู้ใช้ว่าข้ามให้ และข้ามเพราะอะไร** อย่าถอดเงียบ ๆ
