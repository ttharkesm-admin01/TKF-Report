# ขึ้นรอบเดือนใหม่

## สิ่งที่เราทำ (แก้ที่เดียว)

```json
// config/round.json — ปีเป็น พ.ศ. เดือนเป็น 1–12
{ "year": 2569, "month": 8, "status": "draft" }
```

แก้แล้วทั้งเล่มขยับเอง: ปกทุกใบ ท้ายสไลด์ทุกหน้า คอลัมน์เดือนที่กางในตาราง
ช่องที่หน้า `/edit` ให้กรอก และโฟลเดอร์รูปที่ระบบมองหา (`public/photos/2569-08/`)

`status: "draft"` ทำให้ปกเล่มขึ้นป้าย "ฉบับร่าง" (ไม่ติดไปตอนพิมพ์) · เสร็จแล้วเปลี่ยนเป็น `"done"`

จากนั้น build + ตรวจตาม skill `verify` แล้ว commit + push · GitHub Actions deploy ให้เอง

## สิ่งที่ผู้ใช้ทำเอง — ไม่ต้องผ่านเรา

1. **`/edit`** กรอกตัวเลขของเดือนนั้น · ทุกตาราง 12 เดือนรวมอยู่หน้าเดียว
   แต่ละแถวกรอกช่องเดียว มีค่าเดือนก่อนขึ้นให้เทียบ · ปุ่ม "ไม่มีรายการ" สำหรับเดือนที่ไม่มีจริง ๆ
2. **`/arrange`** ลากรูปใส่ทีละบล็อก · ย่อให้อัตโนมัติ · สลับลำดับ ซ่อน ใส่คำบรรยาย
3. ทั้งสองหน้ากดส่งแล้ว commit เข้ารีโปเอง → Actions build → เว็บอัปเดตใน ~1 นาที
4. **`/deck`** ตรวจ แล้ว Ctrl+P ถ้าต้องการ PDF (เลือกแนวนอน + เปิดกราฟิกพื้นหลัง)

ทั้งสองหน้าต้องใช้ GitHub Personal Access Token กรอกครั้งเดียว เบราว์เซอร์จำให้

## จุดที่มักถามซ้ำ

- **รูปไม่ต้องผ่าน git ในเครื่อง** — ผู้ใช้ไม่มีโค้ดบนเครื่อง ลากใส่เว็บอย่างเดียว
- **ค่าที่ยกมาจากรอบก่อน** ยังไม่มีระบบ carry-forward (`docs/PROJECT.md` ขั้นที่ 8)
  ตอนนี้ค่าเดือนก่อนแค่ขึ้นเป็นตัวเทียบในหน้า `/edit` ไม่ได้เติมให้อัตโนมัติ
- **ไม่ต้องกรอกครบ** ขั้น validate ยกเลิกไปแล้ว ช่องที่ว่างก็ขึ้นว่างบนสไลด์
